# Монитор медианных цен WoW (EU Eversong)

## Важно
- Этот проект **не запущен**, пока вы не настроите GitHub Actions.
- В `items.json` подтверждён ID только лечебного зелья (`241305`). Для остальных предметов добавьте ID из ссылок Undermine Exchange. Тип `commodity` подходит для региональных материалов и расходников; для обычных предметов укажите `item`.
- Медиана вычисляется **по количеству выставленных единиц** из `result.auctions`, а не берётся из поля `price` (это минимальная цена). Она может отличаться от показателя Median на сайте: сравните результаты.
- При первом успешном снимке каждого товара уведомление не отправляется. Далее сравниваются **последовательные новые снимки**. Старые данные не считаются новым изменением.
- Если API не возвращает лоты, скрипт не выдумывает медиану.
- Данные для commodities общие по региону EU, для non-commodities используются аукционы Eversong.

## Настройка (GitHub)
1. Создайте **приватный** репозиторий на github.com (например, `wow-auction-monitor`).
2. Загрузите **содержимое папки** проекта, включая скрытую `.github/workflows/monitor.yml` (проще всего через GitHub Desktop или `git`).
3. Откройте `Settings → Secrets and variables → Actions → New repository secret` и добавьте:
   - `UNDERMINE_API_KEY` — **новый** ключ Undermine Exchange (ранее опубликованный ключ лучше перевыпустить).
   - `TELEGRAM_BOT_TOKEN` — токен бота, созданного через Telegram @BotFather.
   - `TELEGRAM_CHAT_ID` — ID вашего Telegram-чата. Чтобы его узнать, напишите боту `/start`, затем откройте `https://api.telegram.org/bot<TOKEN>/getUpdates` **в своём браузере** и найдите `message.chat.id`. Не пересылайте токен или ссылку с токеном другим людям.
4. В `Settings → Actions → General → Workflow permissions` включите `Read and write permissions` (если доступно).
5. Откройте `Actions → WoW auction median monitor → Run workflow` и проверьте лог. При первом запуске будут сохранены базовые медианы без тревоги.
6. Добавьте недостающие ID в `items.json` и запустите workflow ещё раз.

Планировщик GitHub запускает workflow **приблизительно** раз в час; иногда запуски задерживаются. В бесплатных приватных репозиториях действуют лимиты минут GitHub Actions. Сам монитор не требует платных библиотек.

## Пороги
- Тихоцвет и Луносветское лечебное зелье: ±20%.
- Остальные: ±30%.

## Безопасность
Никогда не записывайте API-ключ и токен Telegram в `items.json`, код, `README.md` или историю Git. Храните их только в GitHub Actions Secrets. Файл `state.json` хранит историю **последнего** успешного снимка по каждому предмету и автоматически обновляется в репозитории.

## Проверка качества предметов
ID всех восьми предметов заполнены по Wowhead. Для предметов с несколькими рангами качества использованы предварительные варианты: Кровотерн 236771, Тихоцвет 236767, Освежающая сыворотка 241307, Потенциал Света 241309, Азефит 236775. Перед использованием уведомлений обязательно сопоставьте ID с адресами страниц Undermine Exchange для выбранного качества; совпадение не подтверждено.


## Качество предметов
Выбраны ID **первого ранга (серое обозначение качества)** для предметов с рангами. Не путать с редкостью предмета. Подтверждены: Кровотерн 236770, Тихоцвет 236761, Азефит 236774. ID Сребревицы 236776, Освежающей сыворотки 241307 и остальных пока сохранены из исходной конфигурации; их соответствие первому рангу нужно дополнительно перепроверить по страницам товара.
